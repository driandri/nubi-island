# Audit antislop 010 · Calendar, Nobi haus, dan sudut island

Mode After, sesuai pilihan sesi. Pemeriksaan native memakai build Release dan aplikasi uji terpisah yang memuat komponen Nubi dengan data fiktif.

1. **LOW · C-4** · Ringkasan acara di kartu Calendar dapat melewati batas kartu. Calendar kini hanya berisi nama bulan, tanggal, dan penanda hari ini. Keenam baris tanggal terlihat pada ukuran Compact, Wide, dan Tall. Acara uji tetap terlihat di kartu Agenda dan di Upcoming setelah Calendar diklik.
2. **MEDIUM · R-19** · Banner minum memakai ekspresi Nobi haus dan satu gerakan tetes air untuk menandai kemunculan pengingat. Kode menjalankan satu animasi 650 ms per kemunculan. Pemeriksaan native melihat posisi akhir tetes air dan posisi statis saat Reduce Motion aktif, lalu membuka panel Minum dari banner. Pemeriksaan gambar statis tidak merekam gerakan antar frame.
3. **LOW · C-4** · Sudut atas siku membuat island tampak seperti persegi panjang pada Peek. Latar, bingkai, Glass, dan hit test kini memakai bentuk membulat yang sama. Pemeriksaan visual mencakup pill, Peek, Home, dan banner, serta Classic Black, Apple Glass, dan Accent Glow. Pemeriksaan geometri menolak titik pada sudut transparan dan menerima titik di tengah tepi pill. Klik pill dan tombol tutup diuji pada build Release. Perpindahan pill ke Peek diperiksa pada aplikasi uji dengan transisi state yang sama.

`swift test` lulus 98 tes. Build Release lulus verifikasi tanda tangan dengan `codesign --verify --deep --strict`. Proses uji terpisah sudah ditutup dan build Release dari folder proyek sedang berjalan.
